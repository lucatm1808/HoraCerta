# HoraCerta

📌 Sobre o projeto
Este projeto tem como objetivo auxiliar os alunos a concluírem sua carga horária de atividades complementares, transformando essa etapa da graduação em algo mais leve, organizado e até prazeroso.
Muitos estudantes veem as horas complementares apenas como uma obrigação ou um “peso” no curso. Nossa proposta é mostrar que elas podem ser uma oportunidade de crescimento acadêmico, pessoal e profissional, 
além de aproximar os alunos das diversas iniciativas oferecidas pela universidade.
